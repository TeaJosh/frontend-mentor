## Getting Started

To view the source code of any project in this repository:

1. Clone this repository: `git clone https://github.com/TeaJosh/frontend-mentor.git`
2. Navigate into the repository: `cd frontend-mentor`
3. Open the project folder you want, for example `cd product-preview-card`
4. Open the project in your preferred code editor.
